# Кухонные значения слов — какое растение имеет в виду ПОВАРЕННЫЙ рецепт.
#
# Зачем отдельный файл, а не обычный алиас: обычный алиас проигрывает основному
# имени карточки. А беда как раз в том, что основное имя занято омонимом:
# карточка «Гвоздика» — это садовый Dianthus, и все 1186 рецептов с гвоздикой
# уезжали к цветку вместо пряности. Записи отсюда ПЕРЕБИВАЮТ обычный матчинг.
#
# Правило пополнения: только слова, у которых в кулинарном тексте одно значение,
# а в гербарии есть омоним с тем же основным именем. Ботанические неоднозначности
# («зверобой», «репешок») сюда НЕ идут — их решает человек по своду, а не список.
#
# Формат:  <каноническое имя карточки> = имя, имя, ...
# Карточка ищется по основному имени, латыни или историческому имени.

# Пряность гвоздика — это высушенные бутоны гвоздичного дерева (Syzygium
# aromaticum), а не садовая гвоздика Dianthus.
Гвоздичное дерево = гвоздика, гвоздики, гвоздичка, гвоздички, пряная гвоздика, гвоздика пряная

# «Перец» в рецепте — чёрный перец (Piper nigrum). Карточка «Перец» без латыни
# ловила всё подряд, включая перец водяной (горец) и стручковый (Capsicum).
Перец черный = перец, перцу, перца, чёрный перец, черный перец, перец чёрный, перец черный, перец горошком
