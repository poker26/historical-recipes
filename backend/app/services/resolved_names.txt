#
# Формат тот же, что у plant_aliases.txt: <карточка> = имя, имя, ...
#
# Откуда взялось. В гербарии 7688 имён, которые оспаривают несколько карточек;
# у «ожины» их шесть. Там, где решить по данным нельзя, каждое притязание
# проверено отдельным вопросом «называют ли ЭТО растение таким именем» — по
# одной карточке за раз, без соседа, на который можно опереться (3-4 сентября
# 2026, 8183 ответа).
#
# Почему вопрос именно такой. «Кому из двух принадлежит имя» задавать
# бесполезно: увидев ответ про первую карточку, модель подгоняет второй под
# него. Контрольный опыт: из 68 пар, которым при совместном показе досталась
# одна латынь, порознь 17 разошлись на разные виды — чайот получал латынь
# огурца, медуница первоцвета.
#
# Что сюда попало. Только имена, где ровно один претендент подтверждён, все
# прочие отвергнуты, И подтверждённый при этом самый содержательный из них.
# Последнее условие обязательно: без него «медвежья ягода» уходила арктоусу с
# весом 15, снимаясь с толокнянки с весом 220. Ручаться должна не модель одна,
# а модель вместе с данными.
