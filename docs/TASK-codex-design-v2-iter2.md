# Задание для Codex: итерация 2 — остальные экраны и ассеты в утверждённом стиле

Владелец выбрал направление: **гибрид «B-основа + C-прогулки»**. Нормативная
спецификация гибрида — `docs/design-v2/DECISION.md` (палитра B, Literata + Golos Text,
геометрия B; композиция хаба прогулок из C, перекрашенная в B; герой камеры — чистый,
из A). Твои же материалы первой итерации (`docs/design-v2/README.md`) остаются
источником по вариантам. Все мокапы — 1080×2340, светлая тема, русский текст;
нормативные тексты давай списком рядом с каждым экраном (как в итерации 1).

## Часть 1. Мокапы остальных экранов (в стиле гибрида, по одному варианту)

1. **Карточка растения** (самый важный экран — витрина базы). Дисциплина A в
   B-палитре. Порядок блоков сверху вниз (принят, не менять): имя русское + латынь +
   гравюра; блок безопасности (уровень, опасный двойник — для ядовитого вида покажи
   заметно); вердикт (2–3 строки живого текста); «Применение» (3 действия с
   человеческими подписями); «Состав» (группы веществ, компактно); «Сбор» (часть,
   сезон); «Рецепты» (2 карточки: название, книга, год + «ещё 31»); «Источники»
   (свёрнуто). Контент: Пижма обыкновенная / Tanacetum vulgare, safety «⚠ ядовита,
   не превышать дозы», рецепты «Порошок от глистной болезни — Анненков, 1878».
2. **Коллекция** (таб 3): полевой журнал — сетка находок с фото пользователя,
   фильтры-чипы (Все · Виды · Места · Биотопы), поиск, пустое состояние («Первая
   находка уже рядом» + мягкая иллюстрация). Дневниковый характер B.
3. **Профиль** (открывается с аватара): аватар-растение + ник + уровень; полка
   значков (места и биотопы, с тирами); друзья/подписки; рейтинг — вторичной
   строкой; настройки приватности. Без ленты в этом экране.
4. **Конструктор маршрута** (полноэкранная карта, композиция C в B-палитре):
   состояние выбора области — круг с Lime-ручкой радиуса, панель снизу («Радиус
   1,2 км · ~45 мин · пешком», кнопка «Собрать прогулку»); ВТОРОЙ мокап того же
   экрана — состояние «мало данных»: честное «Здесь мало наблюдений» + кнопка
   «Расширить до 3,6 км» + альтернатива «Гулять свободно».
5. **Активная прогулка**: следующая цель крупно (фото + имя + «идти ~200 м»),
   камера всегда доступна, прогресс «5 из 15», вклад участников (аватары с
   счётчиками), свёрнутый список целей. Награда НЕ на верхнем экране.
6. **Экран ошибки определения** (в стиле гибрида): «Снимок сохранён» + «Вернёмся к
   нему, когда появится связь» + красный грибной дисклеймер на месте.

## Часть 2. Ассеты (PNG с прозрачностью, если не сказано иное)

1. **Иконки таб-бара**, 3 шт × активное/неактивное состояние (Определить —
   ботаническое «растение/лупа», Прогулки — рюкзак/тропа, Коллекция — гербарная
   книга). Тёплые ботанические, единый визуальный вес, узнаваемые в 24–28dp.
   512×512.
2. **Гравюры видов** («ботанические таблицы» как в B-результате: акварельно-
   гравюрный стиль, растение целиком на прозрачном/бумажном фоне, 768×1024).
   Первая партия — 20 видов, ИМЕННО эти (топ реально определяемых у пользователей):
   крапива двудомная, полынь горькая, тысячелистник благородный, сныть обыкновенная,
   черноголовка обыкновенная, малина обыкновенная, чистотел большой, полынь
   обыкновенная, мыльнянка лекарственная, лопух паутинистый, вероника длиннолистная,
   шиповник морщинистый, бодяк полевой, подорожник большой, клевер ползучий, горошек
   мышиный, пижма обыкновенная, осот огородный, липа сердцевидная, иван-чай
   узколистный. Файл называй латинским биномом в snake_case (`urtica_dioica.png`).
   Ботаническая точность важнее красоты: вид должен быть УЗНАВАЕМ (форма листа,
   соцветие); если не уверен в виде — пропусти и напиши, какой пропустил.
3. **Фон-иллюстрация героя камеры** (лёгкая ботаническая графика по краям, центр
   пустой под кнопку, 1080×800, полупрозрачная, в B-палитре).
4. **Пустые состояния** (2 шт, 800×600): коллекция пуста; прогулок рядом нет.
5. **Стиль карты прогулки** (1 референс-тайл 1024×1024: стилизованная карта в
   Map-Mist зелёно-бумажных тонах с тропинками-пунктирами — по нему я настрою
   реальную карту).

## Ограничения — те же, что в итерации 1

Реализуемо в Compose (плоско, скругления, без стекла/3D); только светлая тема;
кириллица (битые надписи дублируй текстом); безопасность не приглушается; состав
блоков экранов из Части 1 — принятые решения, свобода в исполнении.
