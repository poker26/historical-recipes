# HANDOFF → мобильный агент: «Почему может работать» (состав→действие)

**От:** backend-агент. **Дата:** 2026-06-21. Бэкенд готов и публичен. Парный флагман к «С чем дружит».

## Зачем
Второй уникальный grounded-запрос: для растения — какие **действия** статистически связаны с его **веществами** («содержит кверцетин → растения с ним чаще сосудоукрепляющие»). Это «удиви меня» / «почему помогает», **невозможно без вашего корпуса**, не выдумано LLM. Платный слой энтузиаста, на карточке растения рядом с «С чем дружит».

## ⚠️ Это ГИПОТЕЗА, не медсовет — рамка обязательна
Связь идёт ЧЕРЕЗ растения (ассоциация), причинность НЕ доказана. `disclaimer` приходит в ответе — **показывать его громко** над блоком. Формулировки: «ассоциировано», «исторически у растений с этим веществом», НЕ «лечит»/«применяйте».

## Контракт
`GET /api/plants/{id}/compound_insights?limit=10` (хост `flora.begemot26.ru`, публичный, zero-LLM, мгновенный):
```jsonc
{
  "plant_id": "...",
  "disclaimer": "Гипотеза по составу: растения с этим веществом… АССОЦИАЦИЯ, не доказательство и не медсовет…",
  "insights": [
    { "compound": { "key": "кверцетин", "name": "кверцетин" },   // вещество-драйвер
      "action":   { "name": "сосудоукрепляющее" },                // канон. действие (см. словарь действий)
      "support": 12,            // в скольких растениях вещество И действие вместе
      "lift": 20.95,            // во сколько раз чаще случайного
      "p_value": 3.1e-9,
      "strength": "сильная",    // "сильная" | "заметная" | "умеренная" (по p_value) — для бейджа
      "n_plants_with_compound": 26 }
  ]
}
```
- Список уже отранжирован (специфичные драйверы сверху), дедуп по действию. Просто рендерь по порядку.
- Пустой `insights` = «недостаточно данных по составу» — показывай мягко (у многих растений состав беден/класс-уровня).

## UX (рекомендации)
- Заголовок «Почему может работать» / «Любопытное о составе».
- Строка: **«содержит {compound.name} → {action.name}»** + бейдж `strength` («сильная связь»).
- `disclaimer` — баннер над блоком, нейтральный тон.
- Тап по действию (опц.) → список растений с этим действием (`/api/plants?action={action.name}` — действия теперь канонические, синонимы слиты).
- Гейтинг — премиум (как «С чем дружит»): бесплатно превью (1-2 размыто), полностью в платном.

## Что НЕ нужно от бэка
Контракт стабилен, данные предрасчитаны (`compound_action_assoc`). Качество растёт по мере чистки состава/действий (на нашей стороне). Нутри-генерики/витамины/минералы уже отфильтрованы; редкий хвост действий (~17%) пока без канона — у таких веществ инсайт может не появиться (это честно).
