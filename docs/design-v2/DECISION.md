# РЕШЕНИЕ: дизайн-направление v2.0 = гибрид «B-основа + C-прогулки»

Принято владельцем 2026-08-24 по итогам первой итерации (см. contact-sheet.png,
README.md). Этот файл — нормативная спецификация для реализации (`layout_version=2`)
и для второй дизайн-итерации Codex.

## Формула гибрида

- **База = вариант B «Живой полевой дневник»**: палитра, типографика, фотографичные
  карточки, гравюра-иллюстрация в результате определения.
- **Хаб «Прогулки» = композиция варианта C** (карта-в-карточке активной прогулки,
  аватары участников, радиус-превью конструктора с жёлтой ручкой), но перекрашенная
  в B-палитру и B-радиусы.
- **Герой камеры на Home = чистый блок из A** (без фото-подложки: фото конкретного
  растения в кнопке камеры путает «это результат или действие?»); вокруг героя
  допустима лёгкая ботаническая графика.
- **Плотные экраны второй итерации** (карточка растения, коллекция) наследуют
  дисциплину A: строгая сетка, воздух, иерархия — в B-палитре.

## Гравюры видов (ботанические иллюстрации результата)

Пер-видовой ассет; генерим прогрессивно для топ-видов из `identifications`,
раздаём с `botanik.fun/ui/plates/{latin_key с _}.png` (как весь арт). Фолбэк в UI
обязателен: нет гравюры → карточка результата живёт без неё, ничего не ломается.
Комнатные растения и гибриды в список гравюр не входят.

## Что остаётся от текущего клиента

Бандленый арт фасада (nav-иконки, камера, листва) ЗАМЕНЯЕТСЯ новым сетом в стиле
гибрида (вторая итерация Codex). Аватары/венки/медальоны биотопов остаются как есть
(курируемый сет, стилистически совместим).
