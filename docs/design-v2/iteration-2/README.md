## Нормативный текст экранов

### 1. Карточка растения

Порядок блоков фиксирован: идентичность → безопасность → вердикт → применение → состав → сбор → рецепты → источники.

- «Пижма обыкновенная»
- «Tanacetum vulgare»
- «⚠ ядовита · не превышать дозы»
- «Опасный двойник: крестовник Якова»
- «Коротко»
- «Горькая пахучая трава с плотными жёлтыми корзинками. Исторически её применяли против паразитов и лихорадки.»
- «Применение»
- «От глистной болезни»
- «При лихорадке»
- «Для наружных обмываний»
- «Состав»
- «эфирное масло»
- «флавоноиды»
- «горечи»
- «Сбор»
- «Соцветия · июль — сентябрь»
- «Рецепты»
- «Порошок от глистной болезни»
- «Анненков, 1878»
- «ещё 31»
- «Источники»

Вторая карточка рецепта на мокапе показывает геометрию компонента. Её название, книгу и год нужно подставлять только из фактической записи БД; макетная строка не является новым фактом корпуса. То же правило действует для краткого вердикта и применений: финальный клиент получает их из source-backed данных.

### 2. Коллекция

- «Коллекция»
- «34 находки»
- «Найти растение или место»
- «Все · Виды · Места · Биотопы»
- «Иван-чай узколистный» / «Сегодня · Легчищево»
- «Пижма обыкновенная» / «12 августа · Битцевский лес»
- «Клевер луговой» / «9 августа · Нескучный сад»
- «Мята полевая» / «2 августа · Легчищево»
- «Первая находка уже рядом»
- «Определить растение»
- «Определить · Прогулки · Коллекция»

Пустое состояние на макете показано как образец компонента. В реальном состоянии оно заменяет сетку, а не появляется после заполненной коллекции.

### 3. Профиль

- «Профиль»
- «Лесная Оля»
- «Исследователь · 8 уровень»
- «34 находки · 6 мест · 3 биотопа»
- «Значки»
- «Лес · Любитель»
- «Легчищево · Мастер»
- «Луг · Новичок»
- «Все значки»
- «Друзья и подписки»
- «12 друзей · 28 подписок»
- «Найти друзей»
- «Рейтинг · 47 место»
- «Приватность»
- «Кто видит мои находки · Друзья»
- «Показывать меня на карте · Выключено»

### 4. Конструктор маршрута — выбор области

- «Создать маршрут»
- «Пешком»
- «Радиус 1,2 км · ~45 мин · пешком»
- «Здесь можно найти около 15 видов»
- «Собрать прогулку»
- «Настроить маршрут»

Круг, текущая точка и Lime-ручка радиуса должны рисоваться поверх реальной карты интерфейсом. Они не являются частью базового map style tile.

### 5. Конструктор маршрута — мало данных

- «Создать маршрут»
- «Здесь мало наблюдений»
- «Для прогулки на 1,2 км не хватает найденных видов»
- «Расширить до 3,6 км»
- «Гулять свободно»
- «~1 ч 40 мин · подойдёт для велосипеда»

Это не тупиковая ошибка: оба действия доступны, а увеличенный радиус сразу виден на карте.

### 6. Активная прогулка

- «Лес · Легчищево»
- «Идёт»
- «Найдено 5 из 15»
- «Следующая цель»
- «Иван-чай узколистный»
- «Идти ~200 м»
- «Показать на карте»
- «Сфотографировать растение»
- «Участники»
- «Вы · 3»
- «Оля · 2»
- «Цели прогулки · 5 из 15»
- «Завершить прогулку»

Награды не занимают верх экрана. Следующая цель — содержательный hero, камера — постоянно доступное главное действие.

### 7. Ошибка определения / офлайн

- «Определение»
- «Снимок сохранён»
- «Вернёмся к нему, когда появится связь»
- «Добавили в коллекцию без определения»
- «Попробовать ещё раз»
- «Вернуться к камере»
- «Никогда не ешь гриб только по определению приложения»

Кандидат и процент уверенности не показываются. Грибное предупреждение сохраняет Danger-фон, треугольник и прямой текст.
