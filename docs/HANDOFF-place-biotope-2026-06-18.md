# HANDOFF → мобильный агент: GPS→биотоп готов (квест↔биотоп, P2)

**От:** backend-агент. **Дата:** 2026-06-18. Закрывает P2 из `HANDOFF-backend-todo-2026-06-18`.

Недостающий landcover-слой построен: каждому `quest_place` проставлены **биотопы**
(OSM landcover, клипнутый по полигону места → те же 18 канонических биотопов, что и
у растений). 134/134 места обработано (129 с биотопами). Теперь «биотоп → найди
здесь виды этого биотопа» работает.

## 1. Биотопы места: `GET /api/quests/place/{place_id}/biotopes`
```jsonc
{ "place_id": "...", "window": "second-half-06",
  "biotopes": [ {"key": "лес хвойный", "group": "лес", "species_count": 12},
                {"key": "луг",         "group": "открытое", "species_count": 8} ] }
```
- `species_count` — сколько ВИДОВ из набора места (`place/{id}/set`) относятся к этому биотопу.
- `group` — для иконок (`лес/открытое/влажное/субстрат/рельеф/антропогенное/прочее`), как в `?view=field.habitat`.
- Экран «что искать здесь, по среде»: чипы биотопов с числом видов.

## 2. Виды биотопа здесь: `GET /api/quests/place/{place_id}/set?biotope=<key>`
Тот же `place/{id}/set` (карточки видов с `plant_id`/фото/`found`), но **отфильтрован**
до видов запрошенного биотопа. Без `biotope` — полный набор (как раньше, обратно
совместимо). В ответ добавлено поле `"biotope"` (эхо фильтра).

Юзкейс: тапнул чип «лес хвойный» в (1) → `set?biotope=лес хвойный` → список хвойно-лесных
видов этого места.

## Каветы
- `species_count`/фильтр считаются по набору места за окно (`window`, дефолт текущее
  полумесячное) ∩ `plant_biotopes`. Вид без биотоп-тега в фильтр не попадёт.
- Биотопы места — presence-based (есть ли landcover в полигоне), без area-веса. Большой
  диверсный парк (Лосиный остров) → много биотопов (честно); малый сквер → 1-2.
- 5 мест без биотопов (landcover не нашёлся) → `biotopes: []`.
