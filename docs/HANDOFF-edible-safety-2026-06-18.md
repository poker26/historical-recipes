# HANDOFF → мобильный / web агент: блок «безопасность едока» (можно ли это есть)

**От:** backend-агент. **Дата:** 2026-06-18. См. `docs/RFC-edible-safety.md`.

Новый блок `safety` — главный ответ на вопрос едока «не умру ли я / мой ребёнок,
если это съем». Это **ordinal-уровень 0-4**, заменяющий грубый бинарный `is_toxic`
(он больше не первичен — стал производным `level >= 3`). Классификация идёт прямо
сейчас (durable workflow) — у части карточек `safety` появится не сразу.

## Блок `safety` в `GET /api/plants/{id}` (default И `?view=field`)
```jsonc
"safety": {
  "level": 2,                              // 0..4 (см. ниже)
  "label": "условно съедобно",
  "edible_parts":    ["плоды"],            // какие части можно
  "dangerous_parts": ["листья"],           // какие опасны
  "deadly_twin": "болиголов",              // смертельный двойник или null
  "rationale": "короткое обоснование"
}                                          // null = ещё не классифицировано
```
Уровни (worst-case для человека-едока):
| level | смысл | цвет |
|---|---|---|
| **4** | ☠️ смертельно ядовито — не трогать | красный |
| **3** | ☢️ опасно (лекарственное, дозозависимо) — не еда | оранжевый |
| **2** | ⚠️ условно съедобно (нужна обработка / невкусно) | жёлтый |
| **1** | ✅ съедобно | зелёный |
| **0** | ❓ нет данных — НЕ считать безопасным | серый |

## Рендер (важно — это ПЕРВЫЙ блок карточки)
- Крупный бейдж `level` (иконка+цвет+`label`) **вверху**, до всего остального.
- **`deadly_twin` ≠ null** — отдельная заметная плашка «⚠️ Смертельный двойник:
  {twin} — не перепутай!». Это критично: купырь (level 2) съедобен, но похож на
  болиголов; именно мисидент убивает, а не само растение.
- `edible_parts` / `dangerous_parts` — «можно: …», «опасно: …».
- `level: 0` показывай как явное «нет данных → не рискуй», НЕ как зелёный/безопасный.

## Списки и роды
- Карточки списка (`GET /api/plants/`): `safety_level` + `deadly_twin` для бейджа.
- Родовой узел (`rank:"genus"`): `safety` = worst-case по видам + `dangerous_members[]`
  (виды level ≥ 3 с их двойниками). «Вишня вообще» → осторожная огибающая.
- MCP `get_plant`/`search_plants` отдают то же (проксируют backend).

## Каветы
- Идёт классификация — `safety:null` у необработанных; не считай null безопасным.
- `level` — опасность САМОГО растения при правильном определении; двойник отдельно.
- Консервативно: при сомнении уровень повышен (лучше зря предупредить).
