# HANDOFF → backend: дистиллировать «Сбор» (harvest) в reviewed-монограф

**От:** мобильный агент «Что растёт». **Дата:** 2026-06-17.

## Проблема
`?view=field.harvest` — это сырой **свал всех упоминаний из всех источников**, не
проходящий LLM-полировку Слоя 2. У эталонного Хмеля (`fb743008…`, `reviewed=true`):
- `seasons`: **29** формулировок («август», «середина августа», «в начале созревания»,
  «незадолго до полного созревания», «фаза технической спелости…») — всё про одно;
- `where`: **38** местообитаний (с OCR-ятями «лѣса по берегамъ ручьевъ»);
- `parts`: 15 морфо-вариантов (шишки/шишка/шишечки/соплодия/соцветие…).

Клиент склеивал это в простыни — читается ужасно. **Клиент теперь скрывает сырые
массивы и рендерит только `harvest.text`** (если есть). Сейчас `harvest.text = null` →
раздел «Сбор» не показывается вообще.

## Что нужно
Дистиллировать harvest в reviewed-монографе так же, как `uses[].summary` / `compounds[].note`
— LLM уже видит все факты. Достаточно **одного-двух предложений** в `harvest.text`:

> Пример (Хмель): «Собирают шишки (соплодия) в августе–сентябре, в начале созревания —
> когда прицветники золотисто-зелёные и упругие. Растёт во влажных лесах, по берегам рек
> и в зарослях кустарников.»

Контракт (добавить в blob монографа, всё опционально — клиент уже читает):
```jsonc
"harvest": {
  "text": "1-2 предложения: что собирать · когда · где",   // ← ГЛАВНОЕ, клиент рендерит это
  // raw parts/seasons/where можно оставить для RAW/MCP, но в reviewed они не нужны
}
```
- Источник — те же `parts/seasons/where`, схлопнуть в чистую прозу (часть = шишки/
  соплодия; сезон = август–сентябрь, начало созревания; где = влажные леса, берега рек).
- Anti-hallucination те же правила: не выдумывать, опираться на факты набора.

## Заодно (тот же класс)
`culinary` — тоже сырой массив (у Хмеля 8 строк); если дёшево, дистиллировать так же
(или оставить как есть — клиент его пока показывает капнутым). Приоритет — harvest.

`app/services/reader_monograph.py` (polish step) — добавить `harvest.text` в выход LLM

`?view=field` начнёт отдавать чистый «Сбор» без правок клиента.
