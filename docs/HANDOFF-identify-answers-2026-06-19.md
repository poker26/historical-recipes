# HANDOFF → мобильный агент: identify-улучшения готовы (Q1/Q2/Q3)

**От:** backend-агент. **Дата:** 2026-06-19. Отвечает на `HANDOFF-identify-improvements`.
Все три на бэке сделаны/задеплоены. Контракты ниже.

## Q1. Матч по вероятности — ГОТОВО (сервер = источник правды зачёта)
`badge_progress` больше НЕ берёт строго `top_latin`. Читает полный `candidates` JSONB и
засчитывает вид набора, если:
- кандидат с этим видом — топ ИЛИ **near-tie**: `score ≥ 0.85 * top_score` (зазор настраиваемый, `_NEAR_TIE`); ИЛИ
- **родовой матч**: род топ-кандидата = род члена набора (великодушно — «встретил тысячелистник тут»).
Ответ `badge/progress` теперь несёт `matched_keys` (зачтённые) + **`soft_keys`** (родовые «почти»).
- Клиент: для ✓/✗ применяй ту же margin-логику к своим `candidates` (порог 0.85 + родовой), —
  совпадёт с серверным зачётом. `soft_keys` рисуй как «похоже, засчитано».

## Q2. «Рядом» глубже + пагинация — ГОТОВО
`GET /api/quests/nearby?lat=&lng=&limit=15[&biotope=&month=]`:
```jsonc
{ "kind":"nearby", "biotopes":[...], "radius_km":2,
  "items":[ … до limit, тир-порядок сохранён … ],
  "has_more": true, "pool_size": 50 }       // больше нет обрыва на 5
```
- `limit` default 15 (max 40). Один вызов — клиент листает по 5 локально.
- `has_more`/`pool_size` — показывать ли «Показать другие». Кончился пул → «Обновить» (перезапрос, шире радиус).

## Q3. Грибы — движок ДОБАВЛЕН (нужен платный ключ, см. ниже)
`POST /api/identify` получил Form-поле **`kingdom`** (default `plant`). Тумблер «это гриб» на
экране съёмки → шли `kingdom=fungi` (или `гриб`) → роутится на **Kindwise Mushroom.id**.
Бридж не трогали (kingdom разрулит → ведёт в гриб-монограф). Контракт ответа тот же
(`candidates:[{latin,score,…,plant}]`) ПЛЮС:
```jsonc
"safety_notice": "⚠️ Определение грибов по фото НЕ заменяет эксперта… не употребляйте по фото…"
```
- `safety_notice` приходит на КАЖДОМ грибном ответе (даже при ошибке движка) — **рендерь его громко** над результатом. Плюс на карточке — `safety` блок (level + `deadly_twin`), грибы уже классифицированы.
- **СТАТУС: гейт на ключе.** Пока `KINDWISE_API_KEY` не вписан в прод-env, грибной путь
  возвращает `{"error":"Kindwise API key not configured"}` + `safety_notice`. Юзер заводит
  ключ на kindwise.com → бэк подхватит, правок клиента не нужно. Растительный путь не затронут.
