# HANDOFF → мобильный / web агент: родовые узлы (genus nodes)

**От:** backend-агент. **Дата:** 2026-06-18. См. `docs/RFC-reference-granularity.md`.

Новый тип карточки — **РОД** (`rank: "genus"`). Недоопределённые упоминания в рецептах
(«вишня», «полынь», «валериана» без вида) теперь линкуются НЕ на случайный вид, а на
родовой узел-хаб. 69 619 рецепт-ингредиентов уже переехали на роды; 783 родовые карточки.

## Как отличить
`GET /api/plants/{id}` теперь отдаёт поле **`rank`** (`"species"` | `"genus"`).
- **`rank: "genus"`** → это ХАБ, у него ДРУГАЯ форма ответа (ниже). Своих
  ботанических фактов нет — он обобщает виды-члены с атрибуцией.
- **`rank: "species"`** → обычная карточка как раньше, ПЛЮС новое поле
  **`parent`** (`{id, name, name_latin}` или `null`) — ссылка «вверх» к роду.

## Форма ответа рода (`rank: "genus"`)
```jsonc
{
  "id", "name": "Вишня", "name_latin": "Prunus", "rank": "genus", "kingdom": "растение",
  "member_count": 19,
  "members": [ {"id","name":"Вишня войлочная","name_latin"} ],   // виды рода, тапаются
  "uses": [ {"action":"вяжущее", "n_species":4,
             "species":["Вишня обыкновенная","Вишня птичья"],     // у каких видов (cap 8)
             "indications":[...], "sources":[...]} ],             // отсортировано по n_species
  "compounds": [ {"compound":"кверцетин","n_species":7,"species":[...]} ],
  "recipes": [ {"id","name","category","book","year"} ],          // генерик-упоминания рода
  "note": "Род «Вишня» — обобщает виды рода; …"
}
```

## Рендер (рекомендация)
Заголовок «Род: Вишня (Prunus) · 19 видов». Секции:
- **Виды рода** — чипы/список `members`, тап → карточка вида.
- **Что сообщают источники** — `uses` с пометкой «у N видов» + раскрытие каких; то же `compounds`.
- **Рецепты** — как обычно (это рецепты, где вид не уточнён).
- На карточке ВИДА показывай `parent` как ссылку «← род Вишня (все виды)».

## Каветы (v1)
- Инфлексия/инверсия специфичного имени («войлочная вишня» vs карточка «Вишня
  войлочная») может уехать на род, а не на вид — точное имя в карточке вида резолвится
  в вид. Улучшим тиром noun+epithet позже.
- Часть родов ещё не собралась (мало латынь-подтверждённых видов) — добавятся по мере
  чистки латыни (пере-прогон сборки идемпотентен).
- Прозы-`summary` у родового узла пока нет — придёт с масс-регенерацией монографов.
