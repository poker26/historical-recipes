# HANDOFF → мобильный агент: «5 растений рядом» (cold-start база, P1 готов)

**От:** backend-агент. **Дата:** 2026-06-19. Реализует `RFC-cold-start-nearby` п.1-2.

Базовый слой «что растёт рядом» — работает В ЛЮБОЙ точке, без квест-датасета. Это
то, что должно стоять на Home и в пустом состоянии Квестов вместо «квестов нет».

## `GET /api/quests/nearby?lat=&lng=[&biotope=&month=]`
```jsonc
{ "kind": "nearby", "near": {"lat":55.4,"lng":37.1}, "radius_km": 2,
  "biotopes": ["поле/сорное"],          // биотоп ТОЧКИ (WorldCover); [] если нет покрытия
  "items": [ {
     "latin_key": "artemisia_absinthium",
     "name": "Полынь горькая", "latin": "Artemisia absinthium",
     "inat_photo": "https://…",
     "plant_id": "uuid|null",            // есть → тап в монограф; null → только iNat-карточка
     "count": 12,                         // живая частота iNat у точки
     "biotope_match": true                // вид уместен биотопу точки (лидирует в списке)
  } ] }                                   // до 5, ранжировано
```

## Как это работает (зачем доверять списку)
- Живая iNat-частота у точки (адаптивный радиус 2→25км) = «что реально тут встречают».
- **Биотоп точки** определяется по растру **ESA WorldCover** (лес/поле/луг/вода/…), и
  habitat-уместные **корпусные** виды поднимаются вверх. Это чинит «я в поле, а выдача
  лесная» (радиус подмешивал лес). Проверено: лес→Ель/Лещина, поле→Полынь/Амброзия.
- Ранг: (1) корпус + биотоп-уместный → (2) корпус → (3) только-iNat. Внутри — по частоте.

## Рендер
- Карточка «Рядом с тобой»: 5 шт, фото + название + (если `plant_id`) тап → монограф.
- `biotopes` можно показать как подпись «вокруг: поле» (опц.).
- `biotope_match:false` у всех / `biotopes:[]` — значит биотоп не определился (вне покрытия
  растра) → просто показывай по частоте, это норм, не ошибка.

## Каветы / охват
- **Растр-покрытие пока = Москва** (тайл N54E036). Вне его `biotopes:[]` → список
  по чистой частоте (вариант «а»), тоже полезно и работает ВЕЗДЕ. Биотоп-уточнение
  расширяется по мере докачки тайлов WorldCover (backend, без правок клиента).
- WorldCover грубее OSM: **нет подтипа леса** (лиственный/хвойный) — только общий «лес».
- `month` — фенология (опц.), как в `/walk`.
- `biotope=<key>` — ручной override биотопа точки (для отладки/чипов «где ты?»).

## Связанное
`RFC-cold-start-nearby` · `HANDOFF-quest-places-coverage` (места = enrichment, не база) ·
`/quests/walk` (P0, чистая частота — клиент уже может на нём).
